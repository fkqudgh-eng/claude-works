Tampermonkey 유저스크립트

CloudCast 메뉴보드 자동기입
설치 & 사용 가이드

주간메뉴표 .xlsx 파일을 올리면 보드명을 읽어 끼니·요일·코너를 자동으로 파악하고, 미리보기에서 원하는 코너만 골라 메뉴보드에 채워 넣습니다.

버전 v4.4 파일 cloudcast-menu-autofill.user.js 대상 apps.cloud-cast.com/menuboard

준비물

한 번만 준비하면 됩니다

Tampermonkey 확장 프로그램 — Chrome · Edge · Whale 등 크로미움 계열 브라우저에서 동작합니다. 각 브라우저 웹스토어에서 Tampermonkey를 검색해 설치하세요. (Firefox도 지원)

설치하기

  1. Tampermonkey 설치

    브라우저 확장 스토어에서 Tampermonkey를 설치합니다. 설치 후 주소창 오른쪽에 검은·회색 아이콘이 보이면 준비 완료입니다.

  2. 스크립트 파일 열기

    전달받은 cloudcast-menu-autofill.user.js 파일을 브라우저 창으로 드래그해서 열거나, 파일 경로를 주소창에 붙여 넣습니다.

    Tampermonkey가 자동으로 설치 화면을 띄웁니다. 없다면 Tampermonkey 아이콘 → 새 스크립트 만들기에 파일 내용을 붙여 넣고 Ctrl+S 로 저장해도 됩니다.

  3. 설치 버튼 클릭

    설치 화면 상단의 설치(Install) 버튼을 누릅니다. 엑셀 해석용 라이브러리(SheetJS)는 스크립트가 @require로 자동으로 불러오므로 별도 설치가 필요 없습니다.

  4. 메뉴보드 편집 화면 열기

    apps.cloud-cast.com에서 메뉴보드 편집 페이지에 들어가면, 화면 왼쪽 아래에 “메뉴 자동기입” 패널이 나타납니다.

    • 패널 제목줄을 드래그하면 위치를 옮길 수 있습니다.
    • 제목줄을 더블클릭하면 self-test가 실행돼 파싱 로직이 정상인지 즉석 점검합니다.

사용하기

  1. 주간메뉴표 xlsx 선택

    패널의 주간메뉴표 파일 선택에서 이번 주 .xlsx를 고릅니다. 파일 아래에 양식 검증 결과(예: 양식 ✓ 8/8)와 인식된 시트명이 표시됩니다. 여러 시트 중 본표를 자동으로 골라냅니다.

  2. 끼니 · 요일 · 코너 확인

    보드명에서 끼니 / 요일 / 코너가 자동 감지되어 감지: 중식 / 월요일 / 코너1·코너2 처럼 표시됩니다. 자동 인식이 빗나가면 셀렉트에서 직접 지정하거나, 코너를 직접 지정 모드로 바꿔 슬롯별로 고를 수 있습니다.

  3. 미리보기 → 코너 선택 → 기입

    미리보기 → 기입을 누르면 각 코너의 신규 값과 기존 값을 나란히 보여주는 표가 뜹니다. 채울 코너만 체크한 뒤 적용을 누르세요. (아래 참고)

v4.4 새 기능

코너별로 골라서 기입

2메뉴 보드에서 두 코너를 모두 덮어쓰지 않고, 원하는 코너만 선택해 채울 수 있습니다. 체크를 끈 코너는 이름·설명은 물론 플러스바까지 기존 값 그대로 보존되고, 보드 템플릿(1메뉴/2메뉴)도 바뀌지 않습니다.

미리보기 — 중식 월요일 · 코너1·코너2
코너1 열무김치냉국수 · 추가밥 · 갈비만두 … 기입
코너2 (기존 메뉴 그대로 유지) 보존

헤더 체크박스로 전체 선택/해제, 전부 해제하면 적용 버튼이 비활성화됩니다.

알아두기

저장(Save)은 사람이 직접

이 스크립트는 입력칸을 채우기만 하고 Save 버튼은 절대 누르지 않습니다. 내용을 눈으로 확인한 뒤 CloudCast의 저장 버튼을 직접 눌러 확정하세요.

안전장치

되돌리기 — 적용 직후 되돌리기 버튼으로 직전 상태로 복구합니다(여러 단계 저장). 양식 검증 — 다른 양식의 파일이면 양식 ✗로 경고하고 기입을 막습니다. 덮어씀 표시 — 미리보기에서 기존 값이 있는 칸은 노란색 “덮어씀⚠”으로 강조합니다.

잘 안 될 때

증상확인 / 해결
패널이 안 보임 주소가 apps.cloud-cast.com/menuboard/menu/… 편집 화면인지 확인하세요. Tampermonkey 아이콘에서 스크립트가 켜짐 상태인지도 점검합니다.
양식 ✗ 표시 선택한 파일이 이번 주 주간메뉴표 원본인지, 보존식 등 다른 시트를 넣지 않았는지 확인하세요. 코너 라벨(코너1·2·3) 위치가 바뀐 새 양식이면 프로파일 조정이 필요합니다.
끼니/요일/코너 인식 실패 패널의 셀렉트에서 끼니·요일을 직접 지정하고, 코너는 직접 지정 모드로 슬롯마다 골라 주세요.
xlsx 파싱 실패 파일이 .xlsx인지(구형 .xls 아님) 확인하고, 네트워크가 SheetJS(cdn.sheetjs.com) 로드를 막지 않는지 점검하세요.
메뉴 인풋을 못 찾음 편집 화면이 완전히 로드된 뒤 실행하세요. 템플릿(1메뉴/2메뉴)이 렌더링될 때까지 잠시 기다렸다 다시 시도합니다.
