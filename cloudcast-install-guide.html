설치 가이드

브라우저에 Tampermonkey를 설치하고 스크립트를 한 번 등록하면, apps.cloud-cast.com 메뉴보드 편집 화면에서 자동기입 패널이 나타납니다.

버전 v4.4 파일 cloudcast-menu-autofill.user.js 브라우저 Chrome · Edge · Whale

준비물

Tampermonkey 확장 프로그램

크로미움 계열 브라우저(Chrome·Edge·Whale)에서 동작합니다. 아래 크롬 웹스토어에서 Tampermonkey를 검색해 설치하세요. Firefox·Edge 부가 기능 스토어에서도 같은 이름으로 받을 수 있습니다.

설치하기

  1. Tampermonkey 설치

    크롬 웹스토어를 열어 Tampermonkey를 검색·설치합니다. 설치 후 주소창 오른쪽에 아이콘이 보이면 준비 완료입니다.

    크롬 웹스토어 열기

  2. “사용자 스크립트 허용” 켜기

    최신 크롬(138 이상)은 확장이 유저스크립트를 실행하려면 별도 허용이 필요합니다. 주소창에 chrome://extensions/를 입력해 확장 관리 페이지를 열고, Tampermonkey 카드의 세부정보를 누른 뒤 “사용자 스크립트 허용”(Allow user scripts) 스위치를 켭니다.

    • 스위치가 안 보이면 오른쪽 위 개발자 모드를 먼저 켜세요.
    • Edge는 edge://extensions/, Whale은 whale://extensions/에서 동일하게 설정합니다.

  3. 스크립트 등록

    방법 A — 파일로 설치: 전달받은 cloudcast-menu-autofill.user.js 파일을 브라우저 창으로 드래그해 열면 Tampermonkey 설치 화면이 뜹니다. 상단 설치 버튼을 누릅니다.

    또는

    방법 B — 소스 복사: 아래 소스 복사 버튼을 누른 뒤, Tampermonkey 아이콘 → 새 스크립트 만들기 화면의 내용을 모두 지우고 붙여넣기 → Ctrl+S 로 저장합니다.

    엑셀 해석 라이브러리(SheetJS)는 스크립트가 @require로 자동으로 불러오므로 별도 설치가 필요 없습니다.

  4. 설치 확인

    apps.cloud-cast.com의 메뉴보드 편집 페이지에 들어가면 화면 왼쪽 아래에 “메뉴 자동기입” 패널이 나타납니다. 패널이 보이면 설치가 끝난 것입니다.

업데이트할 때

새 버전을 받으면 Tampermonkey에서 기존 스크립트를 열어 내용을 새 소스로 교체하고 저장하면 됩니다. 방법 A로 새 .user.js 파일을 다시 여는 것도 동일하게 동작합니다.

설치가 안 될 때

증상확인 / 해결
설치 화면이 안 뜸Tampermonkey가 먼저 설치돼 있어야 합니다. 설치 후 .user.js 파일을 다시 열거나, 방법 B(소스 복사·붙여넣기)로 등록하세요.
패널이 안 보임주소가 apps.cloud-cast.com/menuboard/menu/… 편집 화면인지, Tampermonkey 아이콘에서 스크립트가 켜짐 상태인지 확인하세요.
붙여넣기 저장이 안 됨“새 스크립트 만들기” 기본 틀을 모두 지운 뒤 소스를 붙여넣어야 합니다. 저장은 Ctrl+S.
브라우저가 다름이 스크립트는 크로미움(Chrome·Edge·Whale)·Firefox의 Tampermonkey에서 동작합니다. Safari는 별도 확장이 필요합니다.
